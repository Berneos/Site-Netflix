# 📺 Site-Netflix

Projeto criado no **1° ano do Ensino Médio Técnico em Informática**, inspirado na interface da Netflix.
Foi desenvolvido por **Breno Martins de Souza** e **Daniel de Jesus Leal** com foco em prática e aprendizado inicial de desenvolvimento web.

> **Atenção:** Todos os direitos referentes a Netflix, filmes e séries utilizados pertencem aos seus respectivos donos.  
> Este projeto foi feito apenas para estudo.

## 📌 Descrição Geral

O *Site-Netflix* é um site simples inspirado no layout da Netflix, desenvolvido quando eu ainda estava aprendendo HTML, CSS e um pouco de PHP.  
O objetivo era praticar:

- Estruturação de páginas com HTML  
- Estilização com CSS e Bootstrap  
- Introdução ao PHP  
- Um pequeno sistema de login utilizando MySQL

Este projeto **não tem objetivo de ser uma cópia funcional da Netflix**, mas sim uma forma de aprendizado.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **Bootstrap**
- **JavaScript**
- **PHP (básico)**
- **MySQL**

## ▶️ Como Rodar o Projeto

1. Baixe ou clone este repositório.
2. Instale o **XAMPP**.
3. Coloque o projeto dentro da pasta `htdocs`.
4. Inicie o **Apache** e **MySQL**.
5. (Opcional) Configure o banco de dados caso queira usar o login básico.
6. Acesse no navegador: `http://localhost/Site-Netflix`

## 📱 Funcionalidades

- Site responsivo usando CSS e Bootstrap  
- Interface inspirada na Netflix  
- Sistema básico de login
